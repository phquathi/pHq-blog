`xhtml2pdf` 是一个 Python 库，用于将 HTML 和 CSS 文件转换为 PDF。它主要用于生成包含复杂布局和样式的 PDF 文档。以下是 `xhtml2pdf` 的一些关键特点和使用方法：

## 特点

1. **支持 HTML 和 CSS**：`xhtml2pdf` 能够解析和渲染大部分的 HTML 和 CSS，使得生成的 PDF 文档可以保持与网页相似的外观。
2. **集成易用**：可以与 Django 和 Flask 等流行的 Python Web 框架轻松集成，适用于生成报告、发票、证书等需要定制布局的 PDF 文件。
3. **可扩展性强**：支持自定义字体、图片、表格等元素，适合复杂文档的生成需求。
4. **开源免费**：`xhtml2pdf` 是一个开源项目，可以自由使用和修改。

## 开发时遇到的问题

这么好用简便并且开源的库，自然也少不了其问题所在。由于其对中文的比较糟糕的支持，导致其无法通过改变css样式比如：

```css
word-wrap: break-word;
white-space: pre-wrap;
overflow-wrap: break-word;
```

上面这种常用的换行样式在这个库中对于中文就无法正常换行。

在网上搜了一圈找到的办法同样没啥用，网上“通用“的做法是在.py文件中引用以下几句代码:

```python
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont
pdfmetrics.registerFont(TTFont('msyh', 'msyh.ttf'))
import reportlab.lib.styles
reportlab.lib.styles.ParagraphStyle.defaults['wordWrap'] = 'CJK'
```

是的，我没看懂并且没用。

### 解决方法

于是我就只能遇事不决暴力出奇迹，直接对需要传进去的html字符串做一个预处理。

对于`xhtml2pdf`库中**A4**大小的纸张，通常为43个中文字符需要换一次行，所以直接遍历html字符串，每当中文符超过43个，就打上一个`<br>`标签！

代码如下：

```python
def insert_manual_line_breaks(html: str) -> str:
    chinese_char_pattern = re.compile(r'[\u4e00-\u9fa5]')

    def add_break_tags(text):
        new_text = ""
        char_count = 0
        for char in text:
            new_text += char
            if chinese_char_pattern.match(char):
                char_count += 1
                if char_count >= 43:
                    new_text += '<br>'
                    char_count = 0
        return new_text
    paragraph_pattern = re.compile(r'(<p>.*?</p>)', re.DOTALL)
    paragraphs = paragraph_pattern.findall(html)

    for paragraph in paragraphs:
        modified_paragraph = add_break_tags(paragraph)
        html = html.replace(paragraph, modified_paragraph)

    return html
```
