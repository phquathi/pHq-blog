DeepSeek V4-Pro 正式版终于来了。

准确地说，**应该是来了。**

截至 8 月 13 日上午，DeepSeek 官网首页已经明确显示 V4-Pro 正式版发布，并称网页端、APP 和 API 均已上线；API 文档中的模型版本也已经出现 `V4-Pro-0813`。

如果只看到这里，这本来就是一次普通的新模型发布。

问题在于，只要再多翻几个页面，事情就开始变得奇怪了。

## 官方自己都没有完全对上

目前最明确的矛盾来自 DeepSeek 官网本身。

一边，官网首页已经写着 V4-Pro 正式版发布，API 文档也已经把模型更新到了 `V4-Pro-0813`。

另一边，官方更新日志最新一篇却依然停留在 7 月 31 日发布的 `V4-Flash-0731`。

更离谱的是，那篇更新日志里甚至还保留着当时的说明：本次更新仅涉及 Flash，Pro 正式版将在之后发布。

也就是说，同一个官方文档体系目前同时存在两种状态：

> 官网首页：V4-Pro 正式版已经全面上线。

> 更新日志：V4-Pro 正式版还没发布。

除此之外，截至本文发布时，V4-Pro-0813 也没有像此前 Flash 正式版那样形成一套完整的发布资料。

完整的 Release Note 没看到，0813 对应的新权重没有公开，此前提到将发布的 DeepSeek Harness 也依然没有出现，官方社交账号的发布节奏同样明显慢于 Flash-0731 当时。

这些事情单独看都不算严重，但同时发生，就让这次发布显得相当不完整。

## 流出的 Agent 跑分却非常漂亮

发布后社区很快流出了一张 V4-Pro-0813 的 Agent Benchmark 表。

如果这张表最终得到官方确认，那么 V4-Pro-0813 的提升其实相当可观。

和 V4-Flash-0731 相比：

* Terminal Bench 2.1：82.7 → **87.9**
* CyberGym：76.7 → **83.3**
* DeepSWE：54.4 → **62.7**
* Toolathlon：70.3 → **74.1**
* AutomationBench：25.1 → **31.8**
* DSBench-Hard：59.6 → **67.2**

其中一些项目已经非常接近表中的 Fable 5。

尤其 Terminal Bench 2.1 的 **87.9 vs 88.0**，基本已经属于同一水平。

这其实非常符合很多人此前对 Pro 正式版的期待。

V4-Pro 的规模是 1.6T 总参数、约 49B 激活参数，而 Flash 只有不到 300B 总参数。Flash-0731 仅靠重新后训练，就已经相较 Preview 出现了非常明显的 Agent 能力提升。

因此大家自然会期待，同一套更成熟的后训练思路应用到 Pro 之后，会进一步释放大模型本身的能力。

从这张表来看，确实像是这么回事。

问题是——**实际使用反馈暂时并没有这么漂亮。**

## 社区体验没有出现 Flash 发布时那种明显提升

Flash-0731 正式版发布的时候，一个很明显的现象是：

官方 Agent 跑分提升很大，而社区把模型接到 OpenCode、Claude Code 等工具之后，也普遍能够明显感觉到它比 Preview 更强。

换句话说，Benchmark 和实际体验基本能对得上。

这次 V4-Pro-0813 暂时没有出现同样的情况。

发布后最初几个小时里，社区反馈相当分裂。

有人认为 Pro 在复杂 Agent 任务上确实更加稳定，但也有相当多用户认为它与 Flash-0731 的区别并不明显，甚至有人在部分 Coding 任务中更喜欢 Flash。

当然，发布十几个小时以内的用户体验并不能作为严谨评测。

不同 Agent、system prompt、reasoning effort、工具协议和上下文管理方式，都可能显著影响结果。

但如果官方流出的数据里 DeepSWE、CyberGym、DSBench 等项目普遍高出 Flash 五到八个百分点，那么现实使用中几乎完全感受不到差距，多少还是让人觉得奇怪。

而 Artificial Analysis 随后公布的结果，又让事情更混乱了一点。

## AA：Pro 53，Flash 52

Artificial Analysis 很快更新了 V4-Pro-0813 的测试结果。

目前的 Intelligence Index：

**V4-Pro-0813：53**

**V4-Flash-0731：52**

只差一分。

严格来说，这个结果并不能直接推翻 DeepSeek 那张 Agent 表。

AA 的 Intelligence Index 是综合评测，其中包含知识、科学推理、Coding、长上下文和 Agent 等不同类型任务；而 DeepSeek 流出的那张表几乎全部集中在 Agent、软件工程和工具使用。

因此完全存在一种可能：

> Pro 的综合基础能力只比 Flash 高一点，但长程 Agent 成功率明显更高。

这两个结论理论上可以同时成立。

不过从模型定位来看，一个 1.6T 的 Pro 正式版最终在综合指数上只比 Flash 高一分，依然很难不让人感到意外。

更何况 AA 自己的页面还出了一个非常喜剧的错误。

## 最搞笑的是，AA 把 Pro 的参数写成了 Flash

截至本文写作时，AA 的 V4-Pro-0813 页面虽然标题明确标注了：

`DeepSeek V4 Pro 0813`

但模型参数却写成了：

**284B total parameters**

**13B active parameters**

这正是 V4-Flash 的规格。

V4-Pro 的官方规格应该是：

**1.6T total / 49B active**

除此之外，AA 页面中的 Open Weights、权重仓库等信息也存在明显的旧数据或元数据混用现象。

于是就出现了一个非常荒诞的场面：

大家本来想通过第三方评测确认 DeepSeek 这次到底发生了什么，结果第三方评测自己的模型页面先把 Pro 和 Flash 的参数写串了。

至少可以确定的是，**AA 当前这个新模型条目的 metadata 还没有整理干净。**

不过需要强调一点：

AA 把参数资料写错，并不能证明它实际测试的也是 Flash。

目前最多只能说明他们建立 V4-Pro-0813 条目时出现了数据继承或录入错误。

至于 DeepSeek API 后台真正提供的 checkpoint 到底是什么，目前没有证据表明存在模型路由错误。

虽然社区已经很自然地开始脑补"是不是把 Flash 接到 Pro endpoint 上了"这种剧情了。

只能说，这个猜想非常有节目效果，但暂时没有证据。

## 所以现在到底是什么情况？

截至 8 月 13 日上午，可以确认的事情其实只有几件。

**V4-Pro-0813 名义上已经正式上线。**

DeepSeek 官网首页和 API 文档都明确指向了新版本，因此单纯认为"正式版根本没有发布"并不合理。

但与此同时，整个发布流程明显没有完成同步。

官方首页、API 文档、更新日志、权重、Harness 和社交媒体的信息并没有像正常正式发布那样形成完整闭环。

更大的问题则是模型能力本身。

目前至少存在三套明显不同的描述：

**DeepSeek 流出的 Agent 数据：**
Pro 比 Flash 明显更强，部分任务已经接近 Fable 5。

**Artificial Analysis：**
Pro 综合 53，Flash 52，两者非常接近。

**社区首批使用反馈：**
整体没有出现 Flash-0731 发布时那种非常明显的代际提升感。

三边目前都无法完全互相解释。

这也是这次 V4-Pro 发布最让人困惑的地方。

它不是单纯的"跑分和体感不一致"，而是从官方发布资料开始，到第三方模型条目，再到实际用户体验，**每一层都有一点地方没有对上。**

## 还不到下结论的时候

现在直接认为 V4-Pro-0813 "只比 Flash 强一点"，可能还太早。

同样，看到那张 Agent 跑分表就认为 V4-Pro 已经全面达到 Fable 5 水平，也明显过度解读了。

真正值得等待的是接下来几件事：

DeepSeek 是否会补上完整的 V4-Pro-0813 更新日志和技术说明；

0813 对应权重是否会正式公开；

此前一直预告的 DeepSeek Harness 是否会发布；

以及第三方在统一 Agent 环境下，能不能复现官方表中 Pro 相比 Flash 的那些提升。

如果之后独立 Agent 测试同样能够跑出 Terminal 87.9、DeepSWE 62.7 这一档表现，那么今天的社区体感问题很可能只是 Harness 和配置差异。

如果最后各种第三方 Agent 测试仍然显示 Pro 和 Flash 基本没有差距，那官方这张跑分表的评测条件就非常值得研究了。

总之，截至现在最准确的描述可能是：

**V4-Pro-0813 已经上线了，但这次发布显然还没有把所有事情说清楚。**

至于到底只是一次文档和发布流程上的"草台班子"，还是后面真的还有什么反转——

再等等看。
