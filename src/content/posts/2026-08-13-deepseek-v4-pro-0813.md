## 官网喊"正式版"，官方却还没跟上

今天（8 月 13 日）打开 DeepSeek 官网首页，已经能看到 V4-Pro 正式版发布的消息，网页端、App、API 全面上线。去 API 文档翻一翻，模型示例里也已经挂上了 `V4-Pro-0813` 的名字。

乍一看这是一场正常的正式发布，直到你去翻官方 changelog——**它还停留在 Flash-0731**。更尴尬的是，changelog 里还留着旧话术，说什么 Pro 的正式版要"之后再发布"。现在 Pro 都正式上线了，这条历史记录还在原地躺着，颇有股"草稿忘了删"的味道。

官方推特的正式发布贴没有，完整的 release note 没有，0813 的权重没有放出来，之前预告要一起发布的 DeepSeek Harness 也迟迟不见踪影。回想 Flash 正式版发布时"文档 + 权重 + note 一条龙"的待遇，这次 Pro 愣是一个都没凑齐。

## 社区跑分和实际体感打架

社区里流出了一张 0813 的 Agent 跑分表：Pro 在 Terminal、DeepSWE、CyberGym 等项目上明显强于 Flash，不少项目甚至非常接近 Fable 5 的水平。

但实际用下来的人普遍没有感受到这么大的提升，有些人甚至觉得和 Flash 用起来差不多。跑分表的"遥遥领先"和真实体感的"也就那样"之间，隔着一整条马里亚纳海沟。

## Artificial Analysis 也来添乱

AA 的反应倒是很快，分数已经出来了：Pro-0813 综合分 53，Flash-0731 是 52。**就一分之差**，打得难解难分。

比分数更离谱的是页面信息。AA 的 Pro-0813 条目一度（截至我写这篇文章时依然）把参数写成了 `284B total / 13B active`——这明明是 Flash 的规格，Pro 应该是 `1.6T / 49B active` 才对。open weights 和权重仓库的信息也跟着乱成一团，整个条目像是从 Flash 那边复制粘贴后忘了改。

## 吐槽时间

所以目前的最大槽点就是：

- DeepSeek 自己的发布页面没同步完整（changelog 还活在 0731，note/权重/Harness 全部缺位）
- AA 新条目的 metadata 串台（把 Flash 的参数安在了 Pro 头上）
- 官方跑分、第三方跑分、社区体感，三者互相都对不上

社区里已经有人开始调侃，说什么"DeepSeek 是不是自己把 Flash 接上去了""API 是不是有 bug 把模型指错了"，这些当段子听听就好——**截至写这篇文章的时候还没有定论**，说不定过两天官方补个 note、AA 改个参数，剧情又要反转。这种首发日的混乱，我已经见怪不怪了。

一句话总结：模型发布了，但发布这件事本身，好像谁都没准备好。
