### 开始

```python
## 绘制sinx与cosx的图像
import numpy as np
import matplotlib.pyplot as plt

x1 = np.arange(0, 10, 0.1)
y1 = np.sin(x1)

y2 = np.cos(x1)

plt.plot(x1, y1, label="sin") # 绘制sin
plt.plot(x1, y2, linestyle="--", label="cos") # 绘制cos，参数"linestyle"表示线条样式
plt.xlabel("x") #x轴名称
plt.ylabel("y") #y轴名称

plt.title("chatgpt") # 标题
plt.legend() # 显示图例

plt.show()
```
